How many ways can you operate computer?
----------------------------------
There are following two ways to operate your computer:
1. GUI - Graphical user interface
2. CLI - Command Line Interface


1. GUI - Graphical user interface
---------------------------------
 - Using graphics like images, icons, and other animated model to operate computers
 - We simply see and click on particular feature and proceed with operating that  
   particular feature in computer.

Note: You as a developer made application's GUI super simple so that now a days anyone in this entire globe can use computer using GUI.

                                                     Hardware
USER  --> Application(Notepad/Whatsapp) --> OS --> [RAM + CPU]
                                                Binary Language(1010101)

Example: WhatsApp:
Features: call, chat, change dp, status others


2. CLI - Command Line Interface:
--------------------------------
 - Here using commands you can operate computers
 - You write some supported/pre-defined commands in your eng language, and your computer  
   starts working accordingly.

                                                        Hardware
USER  --> CLI(Command Prompt/Terminal/bash) --> OS --> [RAM + CPU]
                                                       Binary Language(1010101)

Note: It is not for everyone but its best choice for IT Engineers or Developers


What are the common operations do we do in computer regularly?
-------------------------------------------------------------
1. Create/Open/Delete Files and Folders
2. Opens/Closes Files and Applications
3. Copy and Pasting
4. Others

How to open CLI:
- WINDOW - Command Prompt/Powershell
------------------------------------
- WINDOW + R ---> type cmd or CMD and hit enter
- Click on Search and type Command Prompt and open
